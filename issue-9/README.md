# ASD-STE100 Simplified Technical English – Issue 9 (January 15, 2025)

This is a markdown transcription of the ASD-STE100 standard, Issue 9. It was made by reading each rendered page image. No text-extraction tool was used. [CONVENTIONS.md](CONVENTIONS.md) explains how the visual elements of the PDF are written in markdown: rule boxes, colored example bands, Help (lightbulb) notes, underlines and dictionary entries. [page-map.md](page-map.md) maps every PDF page to its printed page label and to the file that holds it.

## How to find things

- **A rule by number:** `part-1-writing-rules/section-<N>-*/rule-<N>-<MM>.md`, e.g. Rule [3.6](part-1-writing-rules/section-3-verbs/rule-3-06.md) is `section-3-verbs/rule-3-06.md`. All rule statements are listed in one place in [part-1-writing-rules/README.md](part-1-writing-rules/README.md).
- **A rule by subject:** [front-matter/subject-to-rule-index.md](front-matter/subject-to-rule-index.md).
- **A word:** search [part-2-dictionary/index.md](part-2-dictionary/index.md), or search the whole entry, e.g. `grep -A15 '^## abandon (v)' part-2-dictionary/words/a.md`. UPPERCASE headwords are approved; lowercase headwords are not approved.
- **Examples by kind:** example lines are tagged `[STE]`, `[Non-STE]` or `[Neutral]` after the band color in the source, e.g. `grep -rn '\[Non-STE\]' part-1-writing-rules`.
- **What changed in Issue 9:** [front-matter/highlights/](front-matter/highlights/README.md).
