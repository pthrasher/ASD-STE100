# Section 2 – Multi-word nouns

Source: [Issue 9, Section 2 – Multi-word nouns](../../../issue-9/part-1-writing-rules/section-2-multi-word-nouns/README.md) gives the full text and the original examples.

## In software text

Software text frequently contains long groups of nouns, for example in commit subjects, log messages, and the names of configuration values. A reader or an agent can connect the words of a long group in the incorrect sequence. Divide these groups with prepositions or a clause. If the group is the name of a code item, write the identifier in code format ([Rule 10.2](../section-10-code-in-text/rule-10-02.md)). Write the names of products, protocols, and standards in full on each page before you use a shorter form.
