# Section 4 – Sentences

Source: [Issue 9, Section 4 – Sentences](../../../issue-9/part-1-writing-rules/section-4-sentences/README.md) gives the full text and the original examples.

## In software text

Developer text is frequently short because it has no articles, no subjects, or no verbs, for example “File not found” or “Restart service.” This text is possibly not clear to an agent that reads it. Write full sentences, and write words in full, not as contractions. A commit subject line in the imperative is a full sentence. Use Markdown lists for complex text, and connect related sentences with approved connecting words.
