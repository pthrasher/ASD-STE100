# Section 2 – Multi-word nouns

## Summary of the rules

> **Multi-word nouns**
> - Rule [2.1](rule-2-01.md) Write multi-word nouns of no more than three words.
> - Rule [2.2](rule-2-02.md) When a technical noun has more than three words, write it in full.<br>Then, you can use one of these methods to make the technical noun clear:
>   - Give a shorter form of the technical noun.
>   - Use hyphens (-) between words that you use as one unit.
