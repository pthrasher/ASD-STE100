# Section 3 - Verbs

Source: [Issue 9, Section 3 - Verbs](../../../issue-9/part-1-writing-rules/section-3-verbs/README.md) gives the full text and the original examples.

## In software text

Use the imperative for commit subject lines, for the first line of a docstring, and for instructions. Use the simple past tense for something that occurred, and the simple present tense for how the code operates. Log messages, error messages, and commit messages frequently use “-ing” forms, the present perfect, and the passive voice. In software text, the agent is usually known: the user, the client, the server, or the service. Write the agent as the subject, and use a verb for each step, not a noun.
