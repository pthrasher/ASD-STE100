# Section 1 – Words

## Summary of the rules

> **Which words can you use?**
> - Rule [1.1](rule-1-01.md) Use words that are:
>   - Approved in the dictionary
>   - Technical nouns
>   - Technical verbs.
>
> **Part of speech**
> - Rule [1.2](rule-1-02.md) Use approved words from the dictionary only as the specified part of speech.
>
> **Approved meaning**
> - Rule [1.3](rule-1-03.md) Use approved words only with their approved meanings.
>
> **Forms of verbs and adjectives**
> - Rule [1.4](rule-1-04.md) Use only the approved forms of verbs and adjectives.
>
> **Technical nouns**
> - Rule [1.5](rule-1-05.md) You can use words that you can include in a technical noun category.
> - Rule [1.6](rule-1-06.md) Use a word that is not approved in the dictionary, only when it is a technical noun or part of a technical noun.
> - Rule [1.7](rule-1-07.md) Do not use words that are technical nouns as verbs.
> - Rule [1.8](rule-1-08.md) Use technical nouns that are approved in your company, industry, or subject field.
> - Rule [1.9](rule-1-09.md) When you must select a technical noun, use one which is short and easy to understand.
> - Rule [1.10](rule-1-10.md) Do not use regional, slang, or jargon words as technical nouns.
> - Rule [1.11](rule-1-11.md) Do not use different technical nouns for the same item.
>
> **Technical verbs**
> - Rule [1.12](rule-1-12.md) You can use verbs that you can include in a technical verb category.
> - Rule [1.13](rule-1-13.md) Do not use technical verbs as nouns.
>
> **Spelling**
> - Rule [1.14](rule-1-14.md) Use American English spelling unless other official directives tell you differently.
