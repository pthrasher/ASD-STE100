# Section 5 - Procedural writing

Source: [Issue 9, Section 5 - Procedural writing](../../../issue-9/part-1-writing-rules/section-5-procedural-writing/README.md) gives the full text and the original examples.

## In software text

Section 5 is applicable to all text that tells the reader to do a task: installation steps in a README, runbooks, the test steps in a pull request, and instructions for AI agents. The primary readers of this profile are AI agents. If an instruction is not clear, an agent can do an incorrect task, and it does not stop to speak to the writer. Thus, write one instruction in each sentence, in the imperative, with the condition first. If the reader must execute a command, put the command in a code block after the instruction ([Rule 10.3](../section-10-code-in-text/rule-10-03.md)).
