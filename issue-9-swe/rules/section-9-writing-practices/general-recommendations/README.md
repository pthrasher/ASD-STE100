# General recommendations

Source: [Issue 9, General recommendations](../../../../issue-9/part-1-writing-rules/section-9-writing-practices/general-recommendations/README.md) gives the full text and the original examples.

## In software text

The general recommendations (GR) are not STE rules. Issue 9 gives them to prevent typical errors. In software text, these errors are frequent: sentences without the conjunction “that,” Latin abbreviations in documentation, and the possessive form after an identifier. The profile recommends that an agent that writes or changes text uses each recommendation, unless the owner of the text gives a different instruction.
