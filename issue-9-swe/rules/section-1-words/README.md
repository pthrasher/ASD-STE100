# Section 1 – Words

Source: [Issue 9, Section 1 – Words](../../../issue-9/part-1-writing-rules/section-1-words/README.md) gives the full text and the original examples.

## In software text

Section 1 tells you which words you can use in software text. Most decisions of the profile [dictionary](../../dictionary/README.md) have their basis in this section: technical nouns in [nouns.md](../../dictionary/nouns.md) (Rules 1.5 to 1.11) and technical verbs in [verbs.md](../../dictionary/verbs.md) (Rules 1.12 and 1.13). Rule 1.12 is the basis for the software meanings of DEPLOY, PUSH, PULL, RELEASE, and CATCH. Rule 1.3 is also applicable to their Issue 9 meanings. Text in code format is not a word of the text, and it keeps the spelling of the code (Rule 1.14).

## Rules

| Rule | Statement | Status | Mechanical check |
|---|---|---|---|
| [Rule 1.1](rule-1-01.md) | Use words that are: Approved in the dictionary; Technical nouns; Technical verbs. | adapted | suggests |
| [Rule 1.2](rule-1-02.md) | Use approved words from the dictionary only as the specified part of speech. | unchanged | suggests |
| [Rule 1.3](rule-1-03.md) | Use approved words only with their approved meanings. | adapted | none |
| [Rule 1.4](rule-1-04.md) | Use only the approved forms of verbs and adjectives. | unchanged | suggests |
| [Rule 1.5](rule-1-05.md) | You can use words that you can include in a technical noun category. | adapted | none |
| [Rule 1.6](rule-1-06.md) | Use a word that is not approved in the dictionary, only when it is a technical noun or part of a technical noun. | adapted | none |
| [Rule 1.7](rule-1-07.md) | Do not use words that are technical nouns as verbs. | unchanged | none |
| [Rule 1.8](rule-1-08.md) | Use technical nouns that are approved in your company, industry, or subject field. | adapted | none |
| [Rule 1.9](rule-1-09.md) | When you must select a technical noun, use one which is short and easy to understand. | unchanged | none |
| [Rule 1.10](rule-1-10.md) | Do not use regional, slang, or jargon words as technical nouns. | adapted | suggests |
| [Rule 1.11](rule-1-11.md) | Do not use different technical nouns for the same item. | adapted | suggests |
| [Rule 1.12](rule-1-12.md) | You can use verbs that you can include in a technical verb category. | adapted | none |
| [Rule 1.13](rule-1-13.md) | Do not use technical verbs as nouns. | unchanged | none |
| [Rule 1.14](rule-1-14.md) | Use American English spelling unless other official directives tell you differently. | adapted | suggests |
