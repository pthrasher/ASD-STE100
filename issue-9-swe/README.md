# ASD-STE100 Issue 9 – software profile

This is a profile of ASD-STE100 Simplified Technical English, Issue 9, for software text. It uses the rules and the dictionary of Issue 9 for commit messages, error messages, API documentation, instructions for AI agents, and other technical text about software.

The readers of this profile are persons and AI agents. The primary readers are agents.

- The profile is based on the transcription of Issue 9 in [../issue-9/](../issue-9/README.md). Issue 9 is applicable to all topics that the profile does not change.
- The profile is not an ASD publication. ASD did not examine it or give its approval.
- [PROFILE.md](PROFILE.md) tells you how the profile relates to Issue 9.

## If you are an agent

### To write a text

1. Find the type of text in [SCOPE.md](SCOPE.md). If the profile is not applicable to the text, stop here.
2. Read [QUICK-REFERENCE.md](QUICK-REFERENCE.md). It contains all rule statements and the words that writers use incorrectly most frequently.
3. Read the guide for the type of text in [text-types/](text-types/README.md).
4. Find each word that you are not sure about in the dictionary. Use the procedure in [dictionary/README.md](dictionary/README.md). Do not guess the status of a word.
5. For a rule that you must use in detail, read its page in [rules/](rules/README.md).

### To review a text

Do the procedure in [review/README.md](review/README.md). Read [review/LIMITS.md](review/LIMITS.md) before you use a mechanical check. A mechanical check cannot tell you that a text is STE.

## Decisions

Each dictionary entry has a decision: `standard` (from Issue 9) or `accepted` (examined and accepted by the owner of the profile). A new decision has the value `proposed` until the owner examines it. [dictionary/index.md](dictionary/index.md) shows the decision of each entry.
