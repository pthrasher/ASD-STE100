# Rules

Each rule of Issue 9 has a page in this folder. The page gives the rule statement, how to use the rule for software text, software examples, and review notes. Section 10 is new in this profile.

Source: [Issue 9, Part 1 – Writing rules](../../issue-9/part-1-writing-rules/README.md) gives the full text and the original examples.

- **Status** tells you if the profile changes the rule: `unchanged`, `adapted`, or `new`.
- **Mechanical check** tells you how a mechanical check can help for the rule: `detects`, `suggests`, or `none`. No value shows that a check can prove compliance. Refer to [../review/LIMITS.md](../review/LIMITS.md).

`tools/build_swe.py` makes the tables below from the rule pages.
