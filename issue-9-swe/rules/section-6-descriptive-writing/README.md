# Section 6 - Descriptive writing

Source: [Issue 9, Section 6 - Descriptive writing](../../../issue-9/part-1-writing-rules/section-6-descriptive-writing/README.md) gives the full text and the original examples.

## In software text

Section 6 is applicable to text that gives information: the body of a commit message, pull request descriptions, API reference documentation, code comments and docstrings, and log messages. Descriptive text does not use the imperative. The profile makes one decision about this: the subject line of a commit message and the first line of a docstring use the imperative ([Rule 5.3](../section-5-procedural-writing/rule-5-03.md)). The remaining text is descriptive, with a maximum of 25 words in each sentence and one topic in each paragraph.
