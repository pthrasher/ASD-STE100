# Rule 10.4 – Names as verbs

> **Rule 10.4** **Do not use a command, a product name, or an identifier as a verb.**

Related: This rule extends [Issue 9, Rule 1.7](../../../issue-9/part-1-writing-rules/section-1-words/rule-1-07.md) (do not use technical nouns as verbs) and [Issue 9, Rule 1.13](../../../issue-9/part-1-writing-rules/section-1-words/rule-1-13.md) (do not use technical verbs as nouns). Profile pages: [Rule 1.7](../section-1-words/rule-1-07.md), [Rule 1.13](../section-1-words/rule-1-13.md).

## In software text

Software writers frequently make verbs from the names of commands and products, for example “grep the logs,” “curl the endpoint,” “Slack the team,” and “Dockerize the service.” They also make verbs from identifiers, for example “`JSON.stringify` the payload.” The name of a command, a product, or an identifier is a technical noun (Rule 1.5). Rule 1.7 does not let you use a technical noun as a verb.

These verbs cause problems for two types of readers. A person who does not know the command cannot know the action. An agent cannot know if “grep the logs” tells it to use `grep`, or only to find text in the log with a different tool.

Write the name as a noun. Put a command or an identifier in code format ([Rule 10.1](rule-10-01.md)). For the action, use an approved verb or a technical verb from [verbs.md](../../dictionary/verbs.md):

- “Use `grep` to find the errors in the log.”
- “Change the payload to a JSON string with `JSON.stringify()`.”

A product name is a proper noun. Do not put it in code format, unless it is also a command: “Send a message to the team in Slack.”

Some command names are the same as technical verbs of this profile, for example `git commit` and [commit (v)](../../dictionary/verbs.md#commit-v), or `git push` and [push (v)](../../dictionary/verbs.md#push-v). You can use these verbs. The verb in the sentence is the technical verb, and the code span is the command: “Commit your changes with `git commit`.” If a command name is not an approved verb and is not in [verbs.md](../../dictionary/verbs.md), do not use it as a verb. For example, “stash” is not a technical verb of this profile. Write: “Save your changes with `git stash`.”

Rule 1.13 is also applicable. Do not use a technical verb as a noun. Write “the deployment,” not “the deploy.”

## Examples

- [Non-STE] Grep the logs for timeouts.
- [STE] Use `grep` to find the timeout errors in the log.

- [Non-STE] Curl the health endpoint to make sure the service is up.
- [STE] To make sure that the service is available, send a request to the `/health` endpoint with `curl`.

- [Non-STE] Add lodash to package.json and npm install it.
- [STE] To add the `lodash` package to the project, execute this command:

  ```sh
  npm install lodash
  ```

- [Non-STE] Slack the on-call team when the deploy finishes.
- [STE] When the deployment is completed, send a message to the on-call team in Slack.

  (“Slack” is a product name. “Deploy” is a technical verb. Do not use it as a noun.)

- [Non-STE] Dockerize the API service
- [STE] Add a `Dockerfile` for the API service

  (A commit subject line in the imperative.)

## Review notes

- For each verb that is also the name of a command, a product, or an identifier, find if [verbs.md](../../dictionary/verbs.md) registers it. `commit`, `push`, `pull`, and `merge` are registered. `grep`, `curl`, and `stash` are not registered.
- Some command names are approved words with a different meaning. “Find the file with `find`” is correct, because FIND (v) has the same meaning. “Touch the file” is not correct: TOUCH (v) is approved only with the meaning “to be in contact” (Rule 1.3). [kill (v)](../../dictionary/verbs.md#kill-v) is not approved for processes.
- A mechanical check can use a list of command names and product names. It can find them in the position of a verb: at the start of a sentence, after “to,” or with “-ed,” “-ing,” or “-ize” at the end. Thus, the value is `suggests`. The check fails in these conditions:
  - The list does not contain all names.
  - It shows correct text as a possible problem, for example registered verbs (`commit`, `push`) and approved words (`find`).
  - It cannot always find the part of speech of a name. In “the curl output,” “curl” is a noun. In “curl the output,” it is a verb.
  - An automatic correction can replace “grep” with “search,” and “search (v)” is not approved. A word-for-word replacement is frequently not sufficient ([Rule 9.1](../section-9-writing-practices/rule-9-01.md)).
