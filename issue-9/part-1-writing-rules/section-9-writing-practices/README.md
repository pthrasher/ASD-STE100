# Section 9 - Writing practices

## Summary of the rules

> **Different sentence constructions**
> - Rule [9.1](rule-9-01.md) Use a different sentence construction to write a sentence when a word-for-word replacement is not sufficient.
>
> **How to use approved words correctly**
> - Rule [9.2](rule-9-02.md) Use each approved word correctly.
> - Rule [9.3](rule-9-03.md) When you use two words together, do not make phrasal verbs.
>
> **Consistent style**
> - Rule [9.4](rule-9-04.md) When you select terminology or wording, always use a consistent style.
