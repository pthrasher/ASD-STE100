# Section 5 - Procedural writing

## Summary of the rules

> **Sentences**
> - Rule [5.1](rule-5-01.md) Write short sentences. Use a maximum of 20 words in each sentence.
> - Rule [5.2](rule-5-02.md) Write only one instruction in each sentence unless two or more actions occur at the same time.
>
> **Verbs in procedures**
> - Rule [5.3](rule-5-03.md) Write instructions in the imperative (command) form.
>
> **Descriptive statements in instructions**
> - Rule [5.4](rule-5-04.md) When there is a condition that the reader must know about first, start the instruction with a descriptive statement. Then, divide that descriptive statement from the command with a comma.
>
> **Notes**
> - Rule [5.5](rule-5-05.md) Write notes only to give information, not instructions.
